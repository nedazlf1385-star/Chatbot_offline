# 🤖 چت‌بات هوشمند با استفاده از Ollama و Streamlit

## 📌 معرفی پروژه
این پروژه یک چت‌بات هوشمند مبتنی بر مدل زبانی **Gemma 3:1B** است که با استفاده از فریم‌ورک Streamlit و ابزار Ollama توسعه داده شده است.

در این پروژه، کاربر می‌تواند با چت‌بات گفتگو کند، تاریخچه مکالمات خود را ذخیره کند و خلاصه‌ای از مکالمه دریافت نماید.

## ✨ امکانات پروژه
- 💬 امکان گفتگو با مدل هوش مصنوعی Gemma 3:1B
- 🧠 استفاده از Ollama برای اجرای مدل زبانی به‌صورت محلی (Local)
- 💾 ذخیره تاریخچه مکالمات در فایل متنی
- 📝 خلاصه‌سازی هوشمند مکالمات با استفاده از مدل زبانی
- 📥 امکان دانلود خلاصه مکالمه
- 🖥️ رابط کاربری ساده و تعاملی با Streamlit
- 🔒 اجرای مدل به‌صورت محلی بدون نیاز به API Key خارجی

## 🛠️ تکنولوژی‌های استفاده‌شده
- Python
- Streamlit
- Ollama
- Gemma 3:1B
- Requests
- JSON
- Pathlib

## ⚙️ پیش‌نیازها

ابتدا موارد زیر را نصب کنید:

1. نصب Python
2. نصب Ollama از سایت رسمی:

   https://ollama.com/

3. دریافت مدل Gemma 3:1B با دستور زیر:

```bash
ollama pull gemma3:1b
```

## 🚀 نصب و راه‌اندازی

**1. دریافت پروژه از GitHub**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. ورود به پوشه پروژه**

```bash
cd YOUR_PROJECT_NAME
```

**3. نصب کتابخانه‌های موردنیاز**

```bash
pip install streamlit requests
```

**4. اجرای Ollama**

مطمئن شوید سرویس Ollama در حال اجرا است.

**5. اجرای پروژه**

```bash
streamlit run app.py
```

توجه: اگر نام فایل اصلی پروژه متفاوت است، نام آن را در دستور بالا جایگزین کنید.

## 🧩 نحوه عملکرد پروژه

1. کاربر سؤال یا پیام خود را در محیط چت وارد می‌کند.
2. پیام از طریق کتابخانه Requests به API محلی Ollama ارسال می‌شود.
3. مدل Gemma 3:1B پاسخ مناسب را تولید می‌کند.
4. پاسخ در محیط Streamlit نمایش داده می‌شود.
5. کاربر می‌تواند تاریخچه گفتگو را ذخیره کند.
6. با انتخاب گزینه خلاصه‌سازی، متن مکالمه برای مدل ارسال شده و خلاصه آن تولید می‌شود.
7. خلاصه تولیدشده ذخیره شده و امکان دانلود آن وجود دارد.
